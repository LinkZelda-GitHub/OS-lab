pub fn ifup(&mut self) -> Result<()>

Bring up network interface.

Does nothing in case the network is already set up. Otherwise turns on DHCP and waits until an IPv4 address has been assigned.

Returns TIMEOUT error in case DHCP configuration does not finish within 30 seconds.
