Trait PciIoUnit

pub trait PciIoUnit: Sized + Default { }
Expand description

Trait implemented by all data types that can natively be read from a PCI device. Note: Not all of them have to actually be supported by the hardware at hand.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
