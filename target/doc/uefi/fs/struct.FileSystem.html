Struct FileSystem 

Source 
pub struct FileSystem(/* private fields */);
Expand description

High-level file-system abstraction for UEFI volumes with an API that is close to std::fs. It acts as convenient accessor around the SimpleFileSystemProtocol.

Please refer to the module documentation for more information.

Returns Ok(true) if the path points at an existing file.

If the file does not exist, Ok(false) is returned. If it cannot be determined whether the file exists or not, an error is returned.
